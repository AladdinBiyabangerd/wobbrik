## Birbaşa renderdə görünən qalıqlar

- **Home:** normal görünüş əvvəl istifadəçi tərəfindən qəbul edilib; xırda tekstura/ikon fərqləri onu yenidən dizayn etmək tapşırığı deyil. Kiçik/font2-də hero ümumiyyətlə yoxdur: MobileHomeScreen yalnız available>PanelWidth olduqda large-font hero çəkir.04-game-states kiçik/böyük şrift nümunəsində hero var. Bu konkret adaptiv fərqdir; normal Home-u yenidən qurmaq lazım deyil.
- **Şəhər/Görünüş və xəta:** ən böyük kompozisiya/material fərqi. Başlıq və Plan/Görünüş səthləri köhnə düz pill üslubundadır; reference-dəki relief/card iyerarxiyası yoxdur. Xəta görüntüsü yalnız mətn+Yenilə-dir, təsdiqli error illüstrasiyası/paneli yoxdur. Səhnə real bir bina+torpaq fixture-ni çəkir; PNG-dəki5 bina/fontan sayını domain tələbi saymaq olmaz. Real geometry/parts qorunmalıdır. Kamera controls/bottom selected-building card reference ilə eyni deyil. Font2-də scene scroll və Bax sabitdir. Plan disabled mövcud qapalı placement qərarıdır, regression kimi aktivləşdirilməməlidir.
- **İnventar/Binalar:** sahiblik/şəhər seal-i və2-column grid var. Kartlar reference-dən daha düz materiallıdır; real bina artwork-ü card içində xırda qalır, boşluq/başlıq-art nisbəti fərqlənir. Nümunə floors/real siluet fərqi saxta kataloqla əvəz edilmir. Font2-də böyük mətn və kiçik art nisbəti daha kəskindir; scroll işləyir.
- **İnventar/Görünüş:** real preview, category seçimi, kartlar, seçilmiş check və pinned təsdiq var. Preview və hissə kartları reference-in gradient/rim/relyefindən sadə düz səthlərdir; kartların art/boşluq ritmi fərqlənir. Font2-də category/grid scroll arxasındadır, təsdiq görünür. Ayrıca legacy Hissələr route-u da mövcuddur; onu Görünüş ilə eyni screenshot kimi təqdim etmək olmaz.
- **İnventar/Dekor və Bazar/Dekor:** sahiblik/alış ayrılıb, owned cards/list və mağaza grid işləyir. Real tree/bench artwork-ü PNG-dəki platformalı illüstrasiyadan fərqlidir; rəng/çərçivə/parıltı və boşluq nisbətləri də fərqlənir. Fəvvarə əlavə etmək tələb olunmur. Yerləşdir disabled mövcud domain qərarıdır; yeni placement açılmır.
- **Bazar/Binalar, öz elanları, yeni elan, alış təsdiqi:** grid/status/summary/fee/net/action kompozisiyaları artıq var; sıfırdan yenidən implementasiya işləri deyil. Kart/button materialı və art ölçü ritmi reference ilə tam eyni deyil. Yeni elanda breadcrumb ikonu yoxdur; cancel bəzi səthlərdə reference-in ikonlu/reliefli secondary action-undan sadədir. Təsdiq sheet-ində real bina art-ı, qiymət/balans və action-lar var. Dialog-only capture ətrafındakı ağ boşluq app-in ekran rəngi kimi qiymətləndirilmədi.
- **Bina detalı:** hazır məlumat/status/ownership, şüa və kontekst başlığı təkrarlanmır. Art intensivliyi/silueti və panel ölçü ritmi fərqlənir; əlavə real status/satış/silmə məzmunu var. PNG placement düyməsi qapalı domain-ə görə əlavə edilmir. Uzun qiymət touch-scroll, disabled silmə, cache/replay/account-change xüsusi ssenariləri əvvəlki açıq yoxlama kimi qalır.
- **Profil:** native tac lent/shield/avatar/XP/stat var. Parametrlər/Rekordlar qısayolları reference-də əsas panelin daxilindədir, cari normal renderdə panelin altındadır. Lent/shield konturu və işıq/kölgə daha sadədir; panel/art/action nisbətləri fərqlənir. Font2-də body scroll və ad/qısayol horizontal scroll qalır.
- **Profil editoru/avatar:** native editor və avatar seçimləri hazırdır; köhnə “legacy raster qalıb” qeydi artıq cari deyil. Avatar selector reference-də geniş contextual səhifə panelidir, cari renderdə yığcam dialogdur. Editor input/action yerləşməsi və native geri/action materialı reference ilə eyni deyil. Portretlər ayrıca generativ art-dır; exact face pixels kimi qəbul edilmir.
- **Parametrlər:** qruplar, real toggle və dil/support/privacy girişləri var. Switch-in thumb/track üslubu, geri düyməsi və sıra radius/boşluqları reference ilə eyni deyil; böyük şriftdə natural-height rows scroll-a keçir. Yeni dil siyahısı tələb olunmur.
- **Nailiyyətlər:** trophy, XP/shield, medal/progress native inteqrasiyası var. Hero/stat-card ölçü ritmi və shield/relyef reference-dən sadədir. Daha çox achievement və fərqli progress real fixture/domain məlumatıdır, vizual xəta deyil.
- **Rekordlar:** native podium/rank/self rows və scope var. Reference-dəki radial şüalar, podiumun vahid personaj/medal/laurel kompozisiyası daha zəngindir; cari native podium/portret nisbətləri fərqlənir. Font2-də podiumun yerinə sığan list göstərilir; bu mövcud adaptasiyadır, nəticə itkisi iddiası deyil.
